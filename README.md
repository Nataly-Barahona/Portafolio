# Portafolio Personal - Nataly Barahona

Portafolio personal desarrollado con HTML, CSS y JavaScript para presentar información profesional, proyectos, habilidades y contacto.

## Descripción

Este proyecto es una landing page moderna y adaptable que incluye:

- Hero section con presentación personal
- Sección "Acerca de mi"
- Galería de proyectos con enlaces a GitHub y demo
- Barra con tecnologías utilizadas
- DarkMode
- Controles para aumentar y disminuir el tamaño de la letra
- Formulario de contacto

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Características principales

- Diseño responsivo
- Tema oscuro/claro con persistencia en localStorage
- Botones para ajustar el tamaño de texto
- Animaciones al hacer scroll
- Enlaces externos abiertos en una nueva pestaña

## Personalización

Puedes cambiar fácilmente:

- Texto de presentación en `Index.html`
- Colores y estilos en `styles.css`
- Comportamiento de tema y fuentes en `app.js`
- Imágenes y videos dentro de la carpeta `img/`
